# בחירות 26 — מודול IVR

מודול API ניסיוני לימות המשיח, ב-Node.js על Vercel, ללא מסד נתונים.

## התקנה
חברו את הריפו ל-Vercel (Framework Preset: Other). אין צורך במשתני סביבה אם כתובות המקור פועלות.

## הגדרת שלוחה בימות המשיח
```ini
type=api
api_link=https://YOUR-PROJECT.vercel.app/api/index?year=25
```
יש להחליף את YOUR-PROJECT בכתובת הפריסה בפועל.

המודול מנסה לקרוא CSV היסטורי של הכנסת ה-25. אם המקור אינו זמין, הוא משמיע הודעת שגיאה ידידותית. ניתן להגדיר CSV_URL_25 ב-Vercel לכתובת CSV חלופית. למעבר לכנסת ה-26: year=26 ו/או CSV_URL_26.

**מגבלות הגרסה:** מציגה סיכום קולות ואחוזי הצבעה בלבד; אינה מחשבת מנדטים. נדרשת בדיקה מול CSV אמיתי ואימות פורמט התגובה מול מערכת IVR לפני שימוש ציבורי. המטמון בזיכרון זמני ונפרד לכל מופע Vercel.
